# Ejercicio 12 - Creature Lab

Objetivo: integrar listado, detalle y likes en una miniapp completa de extremo a extremo.

Endpoints:

- GET /criaturas
- GET /criaturas/:id
- PATCH /criaturas/:id/like

Resultado: la app carga la colección, selecciona una criatura y actualiza sus likes sin introducir nueva arquitectura.
